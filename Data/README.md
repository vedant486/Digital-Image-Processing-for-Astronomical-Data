# Data

Raw astronomical FITS files are intentionally not committed to Git by default.

Place the downloaded Centaurus A FITS files in `data/raw/`.

Recommended initial surveys:
- DSS2 Red (optical)
- WISE 12 (infrared)
- RASS-Cnt Broad (X-ray)
- NVSS (radio)

Use the same SkyView target, coordinate system (J2000), projection (Gnomonic/Tan),
and output image dimensions for all datasets.

Record the exact SkyView survey names and query settings in the project report so
the dataset can be reproduced.
